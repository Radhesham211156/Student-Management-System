# 🎓 Result Management System

A modern and responsive **Result Management System** developed using **Java, JSP, Servlet, JDBC, MySQL, HTML, CSS, and JavaScript**. This project helps schools and colleges manage student results efficiently.

---

## 🚀 Features

* Admin Login System
* Add Student Records
* Update & Delete Results
* Search Student Results
* Display Marks & Percentage
* Responsive User Interface

---

## 🛠️ Technologies Used

### Frontend

* HTML5
* CSS3
* JavaScript

### Backend

* Java
* JSP & Servlet
* JDBC

### Database

* MySQL

### Server

* Apache Tomcat
